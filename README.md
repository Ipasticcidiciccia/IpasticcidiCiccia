# IpasticcidiCiccia

Web app per la gestione di un'attività di asporto di prodotti alimentari con menù, prenotazioni e pagamenti.

## Caratteristiche

- 📋 Gestione menù dinamica
- 📅 Sistema di prenotazioni
- 💳 Integrazione pagamenti (Stripe)
- 👨‍💼 Dashboard admin
- 👤 Gestione account clienti
- 📱 Responsive design

## Stack Tecnologico

### Frontend
- React 18+
- Tailwind CSS
- React Router
- Axios
- Stripe.js

### Backend
- Node.js + Express
- PostgreSQL (o SQLite per sviluppo)
- JWT Authentication
- Stripe API

### Hosting Gratuito
- Frontend: Vercel/Netlify
- Backend: Railway/Render
- Database: Neon PostgreSQL

## Quick Start

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd frontend
npm install
cp .env.example .env
npm start
```

Vedi `SETUP.md` per istruzioni dettagliate.
